# PRD: 냉모(nengmo) — 장보기 리스트 관리

## 목표
사용자가 자주 가는 가게(마트/대형마트 등)별로 장볼 목록과 가격 메모를 관리해, 매장에서는 실시간으로 체크하고 나중엔 스스로 가격 변동을 파악할 수 있게 하는 MVP.

## 사용자
로그인 없이 한 기기·한 브라우저에서 혼자 쓰는 개인 사용자. 장보러 다니면서 모바일로 리스트를 확인/체크하고, 눈에 띄는 가격을 그 자리에서 기록해두고 싶은 사람.

## 핵심 기능
1. **가게 보드**: 자주 가는 가게를 카드로 등록(이름 + 카테고리 5종 프리셋, 카테고리별 자동 아이콘). 카드 생성/수정/삭제.
2. **장보기 리스트**: 가게별로 살 물건을 이름만 입력해 추가. 체크(구매완료)해도 삭제되지 않고 취소선으로 표시되어 리스트에 남는다.
3. **가격 메모**: 가게별로 상품을 등록(상품명 + 첫 가격을 한 화면에서 함께 입력)하고, 재방문 시 같은 상품에 새 가격 기록을 계속 추가한다. 상품별 가격 이력을 최신순으로 조회.

## MVP 제외 사항
- 로그인/사용자 계정 (추후 추가 예정 — 지금은 단일 로컬 사용자 가정)
- 가격 추이 그래프/시각화 UI (데이터 모델만 대비, 화면은 다음 단계)
- 여러 기기/브라우저 간 데이터 동기화 (서버 저장 없음, 로컬 저장만)
- 가게 간 상품 가격 비교
- 멀티탭 동시 사용 시 실시간 동기화

## 디자인
- 모바일 우선 반응형(장보는 상황에서 폰으로 쓰는 것을 기준으로 설계), 데스크탑에서도 정상 동작.
- 미니멀한 카드/리스트 UI, 카테고리별 lucide-react 아이콘으로 시각적 구분.
- 색상/다크모드 등 세부 비주얼 디자인은 이번 요구사항 정의에서 논의되지 않음 — 기본 라이트 테마로 시작하고 필요 시 별도로 정한다.
